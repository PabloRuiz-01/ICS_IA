# Ejemplos UT 03.1 – Estados y eventos en React con TypeScript

Proyecto Vite + React + TypeScript con un componente por concepto, numerado según el orden de la exposición.

    npm install
    npm run dev

| N.º | Componente | Concepto |
|----|-----------|----------|
| 01 | Ejemplo01_SinEstado | Una variable normal no actualiza la pantalla |
| 02 | Ejemplo02_ContadorBasico | useState |
| 03 | Ejemplo03_Instantanea | El estado es una instantánea por renderizado |
| 04 | Ejemplo04_ReemplazoObjeto | Se reemplaza, no se fusiona |
| 05 | Ejemplo05_ListaTareas | Inmutabilidad |
| 06 | Ejemplo06_FormaFuncional | setX(anterior => ...) |
| 07 | Ejemplo07_ContadorCaracteres | Dato derivado |
| 08 | Ejemplo08_ListaProductos | Estado mínimo y lista filtrada |
| 09 | Ejemplo09_ObjetoEvento | target / currentTarget |
| 10 | Ejemplo10_Burbujeo | Burbujeo y stopPropagation |
| 11 | Ejemplo11_PasarDatos | Pasar datos al manejador |
| 12 | Ejemplo12_Teclado | onKeyDown |
| 13 | Ejemplo13_CampoControlado | Campos controlados |
| 14 | Ejemplo14_AltaBoletin | Formulario sencillo con onSubmit |
| 15 | Ejemplo15_ElevarEstado | Elevar el estado |
| 16 | Ejemplo16_TipadoEventos | Anexo: tipado de eventos |
